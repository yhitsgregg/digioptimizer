# digioptimizer

## Tombola

Draw a random number from 1 to 10. Each **Shake** picks only from the numbers
still in the drum, so a number never repeats within a round. The rack below
shows what's been drawn; once all ten are out, **Refill the drum** starts over.

Open `index.html` in any browser — one self-contained page, no build step or
dependencies.
