# digioptimizer

## Shake

A single-page app that draws a random number from 1 to 10 each time you press
**Shake**. Numbers never repeat — each draw comes from the pool of numbers that
haven't been shown yet. Once all 10 are used the button disables, and **Reset**
starts a fresh round.

Open `index.html` in any browser. No build step or dependencies.
